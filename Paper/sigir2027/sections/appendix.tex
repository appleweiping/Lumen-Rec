\section{Prompts}\label{app:prompts}
All prompts are single-turn chat messages with thinking disabled; the answer is the first generated token, read as \texttt{Yes}
or \texttt{No} by token id from the top-50 log-probabilities. \textbf{V0}, the registered prompt of the rated panels (user
message, no system message):
\begin{quote}\ttfamily\scriptsize\raggedright
You are an expert recommendation system.\\[1pt]
User history (oldest to newest):\\
- \{title\} (rated \{r\}/5) \quad[last 10 events, one line each]\\[1pt]
Candidate item:\\
Title: \{title\}\\
Description: \{first 200 characters, if present\}\\[1pt]
Would this user like the candidate item? Answer with only Yes or No.
\end{quote}
Next-item panels use the same template with plain history lines (last 5 events) and the question \textsf{next} (``Will this user
purchase the candidate item next?'') or \textsf{like}; their prompt stays frozen at V0. The dislike and paraphrase questions and the
threshold question of V1 and V7 (``Will this user rate the candidate item 4 stars or higher (on a 1-5 scale)?'') were fixed in advance
and are scored only after the zero-shot gate (Table~\ref{tab:app-bank}).

\section{Registered Amendments}\label{app:prereg}
Each amendment was written before the data it governs were generated; the registration is a timestamped project document, not an entry
in a public registry. \textbf{Amendment 1} (before any pilot data): scoring, resampling, tie and split conventions and the rebuild of the
next-item panels. \textbf{Amendment 2} (after the pilot gate result, before further GPU jobs): the remedy round, Gate-FT, the plan of the
next-item audit, the diagnosis battery and CPU artifact checks (interpretive and exploratory) and the forking-path rules (immutable
constants 0.60, 0.1863 and 0.65; one prompt round; fixed unit roles; reference rows; claim admission; banned claims).
\textbf{Amendment 3} (before any fine-tuned adapter existed; revised before any outcome statistic of one): data roles, the endpoint
dictionary with the single primary hypothesis P1, the zero-shot panels, the knockout labels, the pruning arms, the nested method slot, the
Llama replication, a within-item permutation control, the Holm families and the cut rules, all conditional on a recorded Gate-FT pass
except the zero-shot panels.

\section{Pseudonym Knockout Protocol}\label{app:pseudonym}
The knockout is a test-time intervention on fixed models (no retraining on pseudonyms). Beyond Section~\ref{sec:tools}: a single-pass,
whole-word, case-insensitive substitution replaces every \texttt{store} string in the history and the candidate text; a stop-list
excludes generic or placeholder stores and strings shorter than four characters or made of digits; pseudonyms are injective within a
panel and never equal a real store string. The placebo maps every brand that the pseudonym arm maps, history-only brands included, to
another real brand of the same tercile of category-wide brand review counts, with identical substituted key sets. Treated candidates are
those whose store string occurs as a whole word in their own title (their share is reported); brand tokens beyond the store field are
not substituted. UAUC is computed over all candidates (primary) and over treated candidates; a NULL label means that pseudonymisation
destroys evidence in that domain.

\section{Reproducibility Checklist}\label{app:repro}
\begingroup\emergencystretch=3em
\begin{itemize}\setlength{\itemsep}{0pt}\setlength{\parsep}{0pt}\setlength{\topsep}{2pt}
\item \emph{Models and scoring.} Qwen3-8B~\citep{yang2025qwen3}, Llama-3.1-8B-Instruct~\citep{grattafiori2024llama3}; vLLM~\citep{kwon2023vllm}
  prefill, at most 4,096 tokens (3,072 in the next-item audit), 100-user chunks.
\item \emph{Fine-tuning.} LoRA~\citep{hu2022lora} on the query, key, value and output projections, $r{=}16$, $\alpha{=}32$, dropout 0.05,
  learning rate $10^{-4}$, cosine decay, 3\% warm-up, one epoch, bf16, effective batch 32 ($8\times4$); at most 24,000 training examples per domain;
  prompts above 1,024 tokens skipped and counted (a domain with more than 2\% such prompts trains with the 99.5th-percentile length
  rounded up to 256); seeds 0, 1, 2 (pruning: five; permutation control: 0 and 1); every seed is reported, and a run that fails its
  integrity checks twice is reported as missing.
\item \emph{Data and hashes.} Training users are the first 1,500 users of each rated domain in seed-0 row order and evaluation users the
  next ones (at most 3,000), disjoint by id. Pilot ML-1M panel 985494c7, pilot Toys panel 69252b48, registered V0 prompts on the pilot
  ML-1M panel 12e83c4f (first eight hexadecimal digits of the sha1); \DATANEEDED{amendment sha1s, rendered prompt-bank sha1, user-id list
  sha1s and the time split $T_d$ of every domain from the freeze record and ftgrid\_split.json}.
\item \emph{Software, compute, artifact.} \DATANEEDED{package versions and GPU model from each report.json; total GPU hours}. Prompts, panel
  builders, scorers, analysis scripts and every result file are released with the anonymous artifact; every number in the paper is read
  from a committed result file.
\end{itemize}
\endgroup
