\section{Pseudonym Knockout Protocol}
\label{app:pseudonym}
Brands come from the Amazon \texttt{store} field. Each brand string is replaced, case-insensitively and
consistently within an example (history and candidates), either by a deterministic invented name (hash-seeded
syllables) or, as a placebo, by another real brand from the same brand-popularity tercile (fixed derangement).
Only candidates whose own title contains their brand string are analysed. Code: \texttt{src/confrec/pseudonymize.py}.
